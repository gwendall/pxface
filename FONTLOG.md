# FONTLOG for PXFACE 3x5

This file records material changes to the PXFACE 3x5 font software and its
PXWORD predecessor.

## 2.0.0 - 2026-08-20

- Renamed the family from PXWORD 3x5 to PXFACE 3x5.
- Changed the Reserved Font Name from “PXWORD” to “PXFACE”.
- Reissued TTF, OTF, WOFF2, WOFF, CSS, and archive packages under PXFACE names.
- Preserved the same printable ASCII glyph set, outlines, and metrics.

## 1.0.0 - 2026-08-19

- Initial public release.
- Includes one Regular style and all 95 printable ASCII characters.
- Provides TTF, OTF, WOFF2, and WOFF builds generated from the canonical PXWORD glyph data.
- Uses proportional advances and a dedicated SPACE glyph.
- Released under SIL Open Font License 1.1 with Reserved Font Name “PXWORD”.

Project and downloads: https://pxface.com/font
