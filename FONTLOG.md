# FONTLOG for PXWORD 3x5

This file records material changes to the PXWORD 3x5 font software.

## 1.0.0 — 2026-08-19

- Initial public release.
- Includes one Regular style and all 95 printable ASCII characters.
- Provides TTF, OTF, WOFF2, and WOFF builds generated from the canonical PXWORD glyph data.
- Uses proportional advances and a dedicated SPACE glyph.
- Released under SIL Open Font License 1.1 with Reserved Font Name “PXWORD”.

Project and downloads: https://pxword.com/font
