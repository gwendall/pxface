# Security policy

## Supported version

The current production release and latest `pxface` npm release receive
security fixes.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/gwendall/pxface/security/advisories/new)
with the affected surface, reproduction steps, and expected impact. If private
reporting is unavailable, contact the maintainer through
[gwendall.com](https://gwendall.com).
